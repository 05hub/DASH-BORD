📋 الخطوات السريعة

1
إنشاء مشروع Firebase
1. اذهب إلى console.firebase.google.com
2. انقر على "إضافة مشروع"
3. أدخل اسم (مثل: 5HUB)
4. اتبع الخطوات
2
تفعيل Firestore
1. من اليسار اختر "Firestore Database"
2. انقر "إنشاء قاعدة بيانات"
3. اختر "بدء في وضع الاختبار"
4. اختر أي منطقة ثم "إنشاء"
3
نسخ بيانات Firebase
1. اضغط ⚙️ "Project Settings" (أسفل اليسار)
2. اختر "Your apps"
3. انقر Web icon
4. انسخ كود Firebase Config كاملاً
4
تحديث index.html
1. افتح index.html بمحرر نصوص
2. ابحث عن "Firebase Configuration" (حوالي السطر 1300)
3. استبدل البيانات الافتراضية ببيانات Firebase
4. احفظ الملف
5
جاهز! 🎉
1. افتح index.html في متصفح
2. استخدم بيانات الدخول (انظر أسفل)
3. جرب من جهاز آخر - نفس البيانات!
