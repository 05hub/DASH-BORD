# الخطوات السريعة لتفعيل Firebase ⚡

## ✅ تم إعداد التطبيق بالكامل!

الآن تحتاج فقط إلى:

---

## 🎯 الخطوات (5 دقائق فقط):

### 1️⃣ إنشاء مشروع Firebase
```
اذهب → https://console.firebase.google.com
انقر → "إضافة مشروع"
أدخل → اسم أي (مثل: "5HUB")
اختر → أي منطقة (مثل: Middle East)
```

### 2️⃣ تفعيل Firestore
```
من اليسار → اختر "Firestore Database"
انقر → "إنشاء قاعدة بيانات"
اختر → "بدء في وضع الاختبار"
اختر → أي منطقة
انقر → "إنشاء"
```

### 3️⃣ نسخ بيانات Firebase
```
اضغط → ⚙️ (Project Settings - أسفل اليسار)
اختر → "Your apps"
انقر → Web icon (</>)
انسخ → كود Firebase Config (من const firebaseConfig = { ... إلى })
```

### 4️⃣ لصق البيانات في index.html
```
افتح → index.html بـ أي محرر نصوص
ابحث → عن "Firebase Configuration"
استبدل → القيم الافتراضية ببيانات firebase الخاصة بك
احفظ → الملف
```

### 5️⃣ جاهز! 🎉
```
افتح → index.html في متصفح
استخدم → اسم المستخدم: owner
         كلمة المرور: 5hubahmed125007@#$
```
